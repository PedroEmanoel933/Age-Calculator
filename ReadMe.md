## 📖 Sobre o Projeto

O **AgeCalculator** é uma **Landing Page** responsiva desenvolvida para realizar o cálculo da idade do usuário de maneira rápida, precisa e intuitiva.

A aplicação permite que o usuário informe sua data de nascimento e receba como resultado sua idade detalhada em **anos, meses e dias**, proporcionando uma visualização mais completa do tempo de vida calculado.

O projeto foi desenvolvido com foco em boas práticas de desenvolvimento Front-End, utilizando uma interface moderna, responsiva e acessível, garantindo uma experiência agradável em diferentes dispositivos, como computadores, tablets e smartphones.

---

## ✨ Funcionalidades

- 🎂 Cálculo automático da idade do usuário;
- 📅 Conversão da data de nascimento em anos, meses e dias;
- ⚡ Processamento dos cálculos utilizando JavaScript;
- 📱 Interface responsiva para diferentes dispositivos;
- 🎨 Design moderno desenvolvido a partir de uma prototipação no Figma;
- 🖱️ Interação dinâmica com os elementos da página.
